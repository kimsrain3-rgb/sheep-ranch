# 바람목장

플레이 중 발견한 버그를 수정하거나 새 기능을 추가할 때는 [버그 기록과 재발 검사](docs/REGRESSIONS.md)를 참고하세요.

양들과 함께 걷고 돌보는 웹 게임입니다. 휴대폰과 PC에서 다음 주소로 플레이할 수 있습니다.

**https://kimsrain3-rgb.github.io/sheep-ranch/**

## 로컬 실행

Node.js가 설치된 환경에서 `npm run dev`를 실행한 뒤 `http://localhost:4173/`을 엽니다. 변경 사항은 `npm test`로 확인합니다.

GitHub Pages의 목동 하루는 바람목장의 공개 대화 서버를 사용합니다. API 키는 서버에 보관하며 서버와 연결할 수 없을 때는 게임의 목장 안내 모드가 대화를 이어갑니다.
